
# Student Records - Map & Filter

This project displays student records using HTML, CSS and JavaScript.

### Features:
- Student name, marks, class and address.
- Uses map() to display student cards.
- Uses filter() to search students by name.
- Shows search results while typing.
- Responsive card layout.

### Files:
- index.html
- style.css
- script.js

### How to Run:
Open index.html in your browser and search for a student by name.
